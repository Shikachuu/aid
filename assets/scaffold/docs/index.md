# Welcome to your new aid site

aid renders this page, `docs/index.md`, as the site's landing page.

## What to do next

- Edit `docs/index.md` to replace this content.
- Add HTML pages, OpenAPI specs (`*.yaml`, `*.yml`, `*.json`), and `.proto` files to `docs/`. aid renders each one as its own route.
- Run `aid dev` to preview with hot reload, or `aid build` to produce a static site under `dist/`.

See [aid.tools](https://aid.tools) for the full feature list.
