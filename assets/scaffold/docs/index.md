# Welcome to your new aid site

This page lives at `docs/index.md` and is rendered as the site's landing page.

## What to do next

- Edit `docs/index.md` to replace this content.
- Drop OpenAPI specs (`*.yaml` / `*.json`) and `.proto` files into `docs/` and they'll render as sibling routes.
- Run `aid dev` to preview with hot reload, or `aid build` to produce a static site under `dist/`.

See the [aid PRODUCT_OVERVIEW](https://aid.tools) for the full feature list.
