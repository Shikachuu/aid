## Not worth it

- `AssetRegistry` class (`assets.ts`): one Map plus one method. A plain function would save about 3 lines and lose the readable JSDoc.
- `stripPrefersDarkBlocks` / `deriveDarkPalette` brace scanning: lightningcss visitors could replace it, but that couples to a transitive dependency.
- `jsx()` `props ?? {}`: the compiler always passes an object, but the guard is one token.
- `requireEmbedded` empty-bytes guard: it gives an actionable error at a real failure point. Keep it.
- `makeCopyAsset` `isInside` check: a trust-boundary guard against path escape. Keep it.
- `renderTemplate` unknown-placeholder throw: user-template validation. Keep it.
- `buildRoutes` `_`-segment filter: `Bun.Glob` has no ignore option.
- Merging `css.d.ts` and `lightningcss-bin.d.ts` into one ambient file: saves one file and nothing else. `bun-types` declares `*.txt` but not `*.css`, so both declarations are needed.
- `jsxs` / `jsxDEV` aliases: the JSX transform requires them.
- `formatSourcePath` quote escaping: moot if the prelude is removed; otherwise correct.
